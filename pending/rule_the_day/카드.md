## 0. 카드 그림은 무엇을 하는 그림인가

조사카드는 **읽는 것**입니다. 글이 본문이고 그림은 그 위에 얹히는 표지입니다.
그래서 그림이 글을 대신하면 안 됩니다 — 카드 본문이 「몸 아래에 뭔가 깔려 있다」
라고 적어 두었는데 그림이 그 물건을 다 보여 주면, 읽을 이유가 사라집니다.

> **그림은 「무엇이 있는가」까지만 그립니다. 「그게 무엇인가」는 글이 말합니다.**

그리고 이 게임에는 **글자가 적힌 카드가 유난히 많습니다**(장부 · 로그 · 기록부 ·
일지 · 명단). 전부 **읽히면 안 됩니다.** 읽히는 순간 그림이 답을 뱉고, 동시에
번역이 깨집니다. 글씨는 **알아볼 수 없는 픽셀 자국**으로만 그립니다 — 줄과 칸의
«생김새»만 남기고 내용은 지웁니다. 요점은 늘 «칸»에 있습니다:
비어 있는 칸 · 지워진 줄 · 줄 수가 다른 두 부.

## 1. 규격

| | |
|---|---|
| 비율 | **1:1 정사각** |
| 내부 해상도 | **320 × 320** |
| 출력 | **니어리스트 네이버로 ×4** 해서 1280×1280. 흐릿해지면 안 됩니다 |
| 팔레트 | **32~40색.** 오프닝·구역과 같은 팔레트입니다 |
| 파일 | `rule_the_day_card_{카드ID}.webp`, 장당 250KB 이하 |
| 구도 | **꽉 채웁니다.** 비워 두는 띠나 여백이 없습니다 |
| 사람 | **없습니다.** 본문이 시신이라고 적은 카드(A1)만 예외입니다 |

**왜 정사각인가.** 예전에는 3:4 세로였습니다. 그런데 화면에서 그림칸은 카드마다
같은 크기로 서야 합니다 — 손패를 옆으로 넘길 때 그림 비율이 카드마다 다르면
아래의 글이 매번 위아래로 뛰고, 그게 «넘겼다»가 아니라 «화면이 바뀌었다»로
읽힙니다. 화면은 이제 그림칸을 정사각으로 못박고(`.cardart`), 협동 퍼즐 판
(`.lift`)도 같은 정사각입니다. 그림도 그 비율로 그립니다.

세로로 긴 물건(일지 · 장부 · 문)은 **잘라내지 않습니다.** 정사각 안에 그 물건을
비스듬히 눕히거나, 위에서 내려다보는 각을 잡아 정사각을 꽉 채우세요 —
「세로 그림을 정사각에 끼워 넣고 양옆을 비우는 것」이 제일 나쁜 답입니다.

## 2. 갈래 덧붙임 — 조사카드에만 붙습니다

```
This is EVIDENCE ART for a single investigation card. SQUARE 1:1, native canvas
320x320. Compose the whole frame edge to edge and leave no band or margin empty.
If the subject is a tall object, tilt it or look down on it so that it fills the
square; never letterbox it with empty strips at the sides.

Draw ONE thing, close and large: the object described below, not the room it sits
in. The viewpoint is that of someone crouching to look at it — slightly above,
close, a little off to one side. The object is described with the crispest pixels
in the frame and everything behind it falls away into dithering and darkness.
No people in frame unless the description explicitly says a body.

Where the object carries writing, the writing is completely illegible: a few
short pixel dashes that read as ruled lines and filled boxes, never as letters
or numbers in any script. What must read clearly is the SHAPE of the record —
which boxes are filled and which are empty.

The object is described below.
```

## 5. 리젝 규칙 (들어올리기 2장 한정)

- **조각에 그림자가 그려져 있으면 리젝** — 높이에 따라 화면이 따로 깝니다
- 조각의 배경이 투명이 아니면 **리젝**. 검정 배경도 리젝입니다
- **손·팔·사람이 그려지면 리젝.** 드는 것은 화면 밖의 셋입니다
- 조각이 세로로 길면 **리젝** — 셋이 좌·중·우로 나눠 잡을 폭이 안 나옵니다
- 조각을 90도 돌렸을 때 위아래가 헷갈리면 **리젝**. 윗면이 밝아야 합니다
- 바닥 그림에 깔린 물건이 무엇인지 알아볼 수 있으면 **리젝**
- 둘의 팔레트와 광원 방향이 안 맞으면 **리젝**. 한 장면이어야 합니다
