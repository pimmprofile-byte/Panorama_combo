# 룰더데이 `rule_the_day` — 배역 초상 4장

**넉 장은 이미 들어가 있습니다.** 이 문서는 다시 뽑을 때 **같은 결로** 나오게
하려고 적어 둔 정본입니다 — 한 사람만 새로 뽑아도 나머지 셋과 나란히 서야 합니다.

화풍은 `비주얼노벨.md` 와 같은 **픽셀아트**이고, 앞머리와 톤 블록도 그 문서의
것을 그대로 씁니다. 시드 `6060`.

---

## 0. 초상은 화면에서 «잘려서» 보입니다

초상은 원본 그대로 안 나옵니다. 화면이 **얼굴 쪽으로 확대해서 동그랗게 잘라
씁니다**(`PORTRAIT_CROP`). 지금 값이 이렇습니다.

| 배역 | 배율 | 세로 초점 |
|---|---|---|
| 데이비드 | ×1.80 | 6.6% |
| 데이먼 | ×1.64 | 16.6% |
| 데이지 | ×1.20 | 3.0% |
| 데이스트 | ×2.05 | 9.1% |

그래서 **머리가 프레임 위쪽에 있어야 합니다.** 인물을 가운데 세우면 잘랐을 때
얼굴이 아래로 밀려 턱만 남습니다. 그리고 **좌우 여백은 버리는 셈** 치고 넉넉히
둡니다 — 확대하면 어차피 밖으로 나갑니다.

> **넷을 나란히 놓고 봤을 때 «머리 크기»가 서로 맞아야 합니다.**
> 데이먼은 아이입니다. 얼굴이 작아야 하는 것이 아니라 **어깨가 좁고 목이 가늘어야**
> 아이로 읽힙니다. 얼굴만 줄이면 「어른을 축소한 것」이 됩니다.

## 1. 규격

| | |
|---|---|
| 비율 | **3:4 세로** |
| 내부 해상도 | **288 × 384** |
| 출력 | **니어리스트 네이버로 ×2~3**. 흐릿해지면 안 됩니다 |
| 잡는 범위 | **허리 위**. 손이 한쪽은 들어옵니다 |
| 배경 | **거의 검정.** 인물만 남기고 다 죽입니다 |
| 파일 | `rule_the_day_portrait_{키}.webp`, 장당 120KB 이하 |
| 키 | `david` · `damon` · `daisy` · `victim` |

## 2. 갈래 덧붙임 — 배역 초상에만 붙습니다

```
This is a CHARACTER PORTRAIT for a murder-mystery game's cast screen. PORTRAIT
3:4, native canvas 288x384. One person only, from the waist up, facing the
viewer at a three-quarter angle.

The head sits HIGH in the frame — the top of the hair is near the top edge and
the eyes fall in the upper third — because the screen crops in toward the face
and anything centred loses its head. Leave generous empty margin at the left and
right; it is cropped away.

The background is almost black and completely empty: no room, no props, no
furniture, no pattern, no logo. The figure is separated from it by a thin
one-pixel RIM LIGHT in that character's colour, tracing the outline of the hair,
one shoulder and one arm — a single hard pixel line, not a glow and not an
outline all the way round.

The whole image is near-monochrome and heavily desaturated: cool dark greys and
bone whites, lit from the front-left. The rim colour is the only saturated
colour in the frame. No text, no signature, no watermark, no UI, no name plate.

The person is described below.
```

## 4. 리젝 규칙 (배역 초상 한정)

- **머리가 프레임 가운데로 내려오면 리젝** — 화면이 잘라 쓰기 때문에 얼굴이 사라집니다
- **배경에 방이나 소품이 그려지면 리젝.** 검정이어야 합니다
- **림라이트가 테두리를 한 바퀴 두르면 리젝** — 한쪽만, 한 픽셀입니다
- 배역 색 말고 다른 채도 높은 색이 들어가면 **리젝**
- 부드러운 그러데이션 · 블러 · 번쩍이는 광원이 있으면 **리젝**
- 넷을 나란히 놓았을 때 **머리 크기와 광원 방향이 안 맞으면 리젝**
- 이름표 · 서명 · 워터마크가 있으면 **리젝**
