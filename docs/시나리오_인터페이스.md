# 시나리오 인터페이스

`scenarios/<id>.py` 하나가 사건 하나입니다. 서버는 이 모듈을 `SC` 라는 이름으로
쥐고 판을 굴립니다. 여기 적힌 것이 그 사이의 계약입니다.

**원칙 하나만 기억하면 됩니다 — 서버는 없는 속성을 전부 `getattr` 로 읽습니다.**
그래서 **안 쓰는 기능은 그냥 안 적으면 됩니다.** 아래 「선택」 표의 것들은
적는 순간 그 기능이 켜지고, 안 적으면 그 화면 자체가 안 뜹니다.

시작은 `scenarios/template.py` 를 복사하는 것입니다. 그 파일이 아래를 전부
최소한으로 구현해 둔 상태이고, 이대로도 판이 처음부터 끝까지 돌아갑니다.

---

## 1. 필수 — 없으면 안 돌아갑니다

### 값

| 이름 | 타입 | 무엇인가 |
|---|---|---|
| `ID` | str | 사건 id. **에셋 파일명 접두사이자 파일 이름**과 같아야 합니다 |
| `TITLE` · `SUBTITLE` | str | 화면에 뜨는 제목 |
| `META` | dict | 사건 선택창에 뜨는 것. `title/subtitle/blurb/players/tone/difficulty/tagline/locked` |
| `MAP` | list | `[{"loc": "A", "name": "구역 이름", "icon": ""}]` — 카드의 `loc` 와 이어집니다 |
| `PHASES` | list | 막. 아래 §3 |
| `CHARACTERS` | list | 배역. 아래 §4 |
| `CARDS` | list | 조사카드. 아래 §5 |
| `AP_BY_ROUND` | dict | `{라운드: 조사 횟수}`. 0이면 그 라운드엔 안 뒤집니다 |
| `HAND_LIMIT` | int | 손에 남길 수 있는 카드 수 |
| `COMMON_INTRO` · `VICTIM` · `SCENE_NOTE` · `VICTIM_CARD` | | 다 같이 읽는 도입부 |
| `TRUTH_FULL` | str | 진상 정본. **채점 프롬프트가 이걸 정답으로 씁니다** |
| `FINAL_QUESTIONS` | list | 종막 서술 질문 |
| `ENDINGS` | dict | `{키: {"name","tone","desc"}}` |
| `OPENING_CUTS` | list | 오프닝 비주얼노벨. `[{"img","fx","lines":[...]}]` |
| `CULPRIT_ID` | str | 진범의 배역 id. 없는 판이면 `""` |

### 함수

| 이름 | 돌려주는 것 |
|---|---|
| `get_character(cid)` · `get_card(cid)` | 그 항목 dict 또는 None |
| `phase_by_seq(seq)` | 그 막 dict |
| `public_card(cid)` | **전체공개된 카드로 나가는 몫.** 여기 안 적은 필드는 플레이어에게 안 갑니다 |
| `private_sheet(cid)` | 그 배역 본인만 보는 롤카드 |
| `public_scenario()` | 모두가 같이 받는 몫. 여기 없는 것은 화면에 아예 안 뜹니다 |
| `obligatory_cards_upto_round(rnd)` | 그 라운드에 저절로 공개되는 카드 id 목록 |
| `memory_up_to(cid, seq, crisis_solved=None)` | `[{"when","text"}]` |
| `interlude_for(seq)` | 막간 방송 문자열 또는 None |
| `build_play_prompt(c, seq, revealed, table, nudge="", hand_ids=None, crisis_solved=None)` | AI 배역이 한마디 할 때 쓰는 프롬프트 |
| `build_final_answer_prompt(c, revealed, table)` | 종막 서술 답변 프롬프트 |
| `build_grade_prompt(c, answers)` | 채점 프롬프트 |
| `compute_ending(grades)` | 엔딩 dict 또는 None(아직 채점 미완) |

## 2. 선택 — 적으면 그 기능이 켜집니다

| 속성 | 켜지는 것 |
|---|---|
| `NPCS` | 고를 수 없는 인물. 좌석엔 안 들어가고 인물 정보에만 뜹니다 |
| `NPC_LINES` | `{seq: [{"who","say"}]}` — 그 막에서 NPC가 대화창에 꺼내는 말 |
| `NPC_VOTES` | NPC의 지목표. `{id: {"default","rules":[{"ifRevealed","vote","why"}],"note"}}` |
| `ROOMS` | 구역 배경 그림. `[{"key","loc","name","art"}]` — **이게 없으면 파일을 넣어도 안 뜹니다** |
| `BELONGINGS` | 소지품. 각자 처음부터 지니고, 1차 지목 최다 득표자가 그 자리에서 압수당합니다 |
| `BELONGINGS_ORDER` | 압수가 겹칠 때의 공개 순서 |
| `NIGHT_ACTS` | 「밤」 막. 각자 몰래 하나를 고르고 아침에 결과가 나옵니다 |
| `ASK_SHEET` | 질문지 막. 끄덕임/저음만으로 답이 옵니다 |
| `CRISIS` | 판 중간의 비상 미니게임 |
| `DECISION` · `DESTINATIONS` | 종막 직전의 갈림길 선택 |
| `VAULT_DOCS` | 다 같이 읽는 서류 (조사로 여는 카드가 아닙니다) |
| `ZONE_LOCK` | 라운드별 구역 잠금 |
| `PHASE_REVEAL` | `{seq: [카드id]}` — 그 막이 열리면 저절로 테이블에 오릅니다 |
| `CARD_PAIRS` | 짝 카드 표시 |
| `INTERROGATE` · `INTERROGATE_SELF` · `INTERROGATE_ONCE` | 심층심문의 대사와 판정 |
| `TURN_ORDER` | 조사 순번 고정 |
| `INVEST_AI` | AI 배역의 조사 성향. `{id: {"home":[loc], "interest":{카드id: 가중치}, "role": "normal"\|"troll"}}` |
| `CHAT_AI` · `CHAT_NUDGES` · `CHAT_FALLBACK` | 자율대화의 결과 톤 |
| `MEMORY` | 막이 지날 때 떠오르는 기억 |
| `KEEP_GOALS` | 「끝까지 지키면 점수」인 목표 |
| `TIMELINE` | 진상 공개 때 읽는 시각표 |
| `ALIBI_LOG` · `ALIBI_HEAD` · `ALIBI_NOTE` | 판이 열릴 때 대화창에 흐르는 증언 |
| `VICTIM_STAGES` | 막마다 갈아 끼우는 피해자 카드 |
| `POD_CODE` · `POD_KNOWERS` · `POD_SEATS` | 탈출 기믹 |
| `private_notes(role_id, card_id)` | 그 배역에게만 붙는 카드 메모 |
| `get_npc(cid)` | NPC 조회. `NPCS` 를 쓰면 같이 넣습니다 |
| `set_room_state(...)` | 서버가 방 상태를 시나리오에 넘겨줘야 할 때 |

## 3. `PHASES` — 막

```python
{"seq": 2, "key": "invest", "name": "1차 조사", "round": 1, "min": 14, "ap": 3,
 "quota": [{"label": "현장", "locs": ["A","B","C"], "n": 3}],
 "gm": "진행자가 읽는 지문."}
```

`key` 가 화면을 정합니다.

| key | 화면 |
|---|---|
| `open` | 오프닝 (비주얼노벨) |
| `invest` | 조사턴 |
| `talk` | 토론 (심층심문이 여기서 열립니다) |
| `accuse` | 1차 지목 — 비밀투표 |
| `ask` | 질문지 (`ASK_SHEET` 필요) |
| `night` | 밤 (`NIGHT_ACTS` 필요) |
| `decision` | 갈림길 (`DECISION` 필요) |
| `final` | 최후의 선택 — 서술 답변 + 지목 |
| `reveal` | 진상 공개 |

`round` 는 조사 라운드입니다 — 카드의 `round` 와 짝을 이룹니다. `ap` 는 그 막의
조사 횟수인데, 실제로는 `AP_BY_ROUND[round]` 가 판정에 쓰이므로 둘을 맞춰 둡니다.

**GM 지문에는 «판을 어떻게 굴리는가»만 적습니다.** 무엇이 수상한지, 누구에게
무엇을 물으라는 지시는 안 적습니다 — 그건 앉은 사람들의 몫이고, 대신 해주면
몰입이 깨집니다.

---

## 4. `CHARACTERS` — 배역

필수는 `id · name · job · color · tagline · persona · hidden · goals` 입니다.
나머지는 있으면 화면이 채워지고, 없으면 그 칸이 안 뜹니다.

| 키 | 어디에 뜨는가 |
|---|---|
| `hook` | 롤카드 첫 장. 1인칭으로 이 배역의 처지 |
| `storyPast` · `storyToday` | 「지난 과거」 · 「오늘, 일어난 일」 |
| `past` | `[{"w": 시각, "t": 일}]` — 「사건 당일, 나는」 타임라인 |
| `hide` | 감출 것. ★ 가 많을수록 치명적이라는 뜻으로 씁니다 |
| `goals` | `[{"t": 목표, "p": 점수}]` — 종막 채점의 축 |
| `sins` | 채점자가 「이 배역의 죄」로 읽는 목록 |
| `tips` | 진행자 참고용. `private_sheet` 에서 내보낼지는 각자 정합니다 |
| `knows` | 판 시작부터 아는 카드 id |
| `look` · `known` | 인물 정보 화면 |
| `ai_note` | **AI가 맡았을 때의 연기 지시.** 무엇을 절대 말하면 안 되는지를 여기 적습니다 |

`ai_note` 가 이 판의 난이도를 실질적으로 정합니다. 「★ … 는 어떤 압박에도
끝까지 말하지 마라」 를 안 적으면 AI가 두 번째 질문에서 다 붑니다.

---

## 5. `CARDS` — 조사카드

필수는 `id · loc · locName · round · title · text` 입니다.

| 키 | 뜻 |
|---|---|
| `spot` | 구역 안 어느 자리인가. 현황판에 뜨는 이름 |
| `hint` | 이 카드로 무엇을 해야 하는지. **결론은 안 적습니다** |
| `reveal: "obligatory"` | 그 라운드에 저절로 전체공개 |
| `auto: True` | 뒤져서 못 엽니다 — 판이 때가 되면 엽니다 |
| `owner` | 그 배역은 이 카드를 못 엽니다 (자기 자신은 못 뒤진다) |
| `requires` | 먼저 밝혀져야 하는 카드 id |
| `combo: [id, id]` | 두 조각이 다 나오면 저절로 열립니다. 조사턴을 안 씁니다 |
| `gone: 3` | 3라운드부터 그 자리가 사라집니다 |
| `bait: True` | 미끼. AI 가중치와 채점에 씁니다 |
| `hot: True` | 화면에서 붉게 |
| `shared: True` | 한 사람이 독점하지 않고 다 같이 봅니다 |
| `unlocks` | 이 카드가 여는 것 (`"pod"` 등) |

**본문에 판단을 적지 않습니다.** 보이는 것만 적고, 그게 무슨 뜻인지는
앉은 사람이 정합니다. `hint` 도 결론이 아니라 «이 카드로 무엇을 물어야 하는가»
까지만 적습니다.

---

## 6. 대화창에 줄을 흘려보낼 때

판이 스스로 하는 말(알리바이 · 막 머리 · NPC · 밤의 결과 · 소지품 반응)은
서버가 `drip` 표를 달아 내보내고, 클라이언트가 **줄 길이에 맞춰 한 줄씩** 답니다
(360ms + 글자당 20ms, 최대 1.9초). 사람이 친 말은 여기서 빠집니다.

대목이 바뀌는 자리에서 멈춰 세우고 싶으면 `ALIBI_LOG` 의 줄에 `"stop": True` 를
답니다. 대화창이 거기서 서고 「계속 ›」을 눌러야 이어집니다.

---

## 7. 붙이는 절차

1. `scenarios/template.py` → `scenarios/<id>.py` 로 복사
2. `ID` 를 파일 이름과 같게
3. `scenarios/__init__.py` 의 임포트 · `_MODS` · `_ORDER` 에 추가
4. 에셋 프롬프트를 쓸 거면 `pending/<폴더>/` 를 만들고 `server.py` 의
   `_ASSET_SETS` 에 한 줄
5. 로비와 관리자 화면은 `/api/scenarios` 를 읽어 저절로 집어갑니다 — 손으로
   적는 자리가 없습니다
