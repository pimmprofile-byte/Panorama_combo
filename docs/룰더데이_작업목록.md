## 2. 1차 / 2차 탭 구조

이 시나리오에는 밤이 없습니다. 조사 현황을 **1차 / 2차 탭**으로 가릅니다.

- **1차** 카드 **9장** · 조사턴 **3턴** — 3턴으로 아홉 장을 다 볼 수 있게
- 그 뒤 질문지 진행 → **개발자 개입** → **2차 조사** 조사턴 **2턴**
- 퍼즐카드는 **판 내내 전체공개** 상태로 둔다
- 퍼즐카드에 **열쇠 표시**를 붙여 「이건 퍼즐이다」를 노출한다 (SVG 작업은 나중)

지금은 `AP_BY_ROUND = {1:2, 2:3, 3:3}` 이고 라운드가 셋입니다. 위 구조로 가면
**라운드 둘 · AP 3/2** 로 다시 잡아야 합니다.

## 4. 방탈출 페이즈

**진입** — 열쇠 반쪽 둘(`하늘 열쇠 반쪽`·`바다 열쇠 반쪽`)이 인벤토리에 모이면
**자동으로** 페이즈가 진행된다.

1. 「세상의 끝... 이 보인다. 하지만 잠겨 있다.」
2. 열쇠를 가진 플레이어가 **장착**하면 해금
3. 지금까지 모은 도구로 퍼즐을 푼다 — **도구를 «고르는» 것이 문제**
4. 마지막 퍼즐은 도구가 하나뿐이므로 **어느 슬롯에 넣는가**가 문제
5. **실패하면 문이 닫히고** 정상 페이즈로 돌아간다
6. 다 풀면 **엔딩이 나온 뒤 다시 머더미스터리로 이어간다**

퍼즐 기획은 따로 받기로 했습니다.
