# 콤보 퍼즐 보관함

《RULE THE DAY》에서 **덜어낸 퍼즐과 보상**을 그대로 옮겨 적어 둡니다.
COMBO 시나리오에서 재활용할 몫입니다 — 지웠다가 다시 짜지 않으려고 남깁니다.

2026-08-05 기준. 옮겨온 곳은 `scenarios/rule_the_day.py`.

---

## 1. 덜어낸 퍼즐 — 열쇠 반쪽 둘

열쇠 반쪽이 **도구가 아니라 입장권**이 되면서(작업목록 §6) 그 위에 붙어 있던
자물쇠를 뺐습니다. 그 자리에 가는 것 자체가 이미 다른 퍼즐(`F1`·`D4`)을 푼
대가라, 한 겹을 더 얹으면 반쪽 둘이 영영 안 모이고 **방탈출 막이 통째로
안 열립니다.** 두 문항 다 문안이 자리표시자 상태였습니다.

| | |
|---|---|
| 원래 카드 | `E0 하늘 끝` (구역 E · 하늘 끝 · 1라운드) |
| 문항 | [자리표시자] 하늘 끝 — 걸린 것을 빼내려면? |
| 정답 | `하늘` |
| 힌트 | [자리표시자] |
| 보상이었던 것 | 하늘 열쇠 반쪽 (지금은 퍼즐 없이 그 자리에서 집는다) |

| | |
|---|---|
| 원래 카드 | `G0 바다 끝` (구역 G · 바다 끝 · 1라운드) |
| 문항 | [자리표시자] 바다 끝 — 뱃머리에 박힌 것을 빼내려면? |
| 정답 | `바다` |
| 힌트 | [자리표시자] |
| 보상이었던 것 | 바다 열쇠 반쪽 (지금은 퍼즐 없이 그 자리에서 뽑는다) |

**COMBO 에서 쓸 때** — 「같은 물건의 반쪽이 두 구역에 나뉘어 있다」는 뼈대는
그대로 좋습니다. 다만 **반쪽을 얻는 데 자물쇠를 걸려면, 그 구역에 들어가는
데는 자물쇠를 걸지 마세요.** 둘을 겹치면 진입 자체가 확률이 됩니다.

## 2. 없어진 보상 — 도구에서 빠진 넷

도구를 셋(`회색조작기`·`게임팩`·`전기`)으로 묶으면서, 아래 넷은 도구 자리에서
빠졌습니다. **퍼즐 문항 자체는 남아 있고 보상만 조사카드로 바뀌었습니다** —
문항이 필요하면 아래 표에서 카드를 찾아 그대로 가져가면 됩니다.

| 원래 카드 | 문항 · 정답 | 없어진 도구 | 지금은 |
|---|---|---|---|
| `C4 전기공급 수동발전기` | 세그먼트 세 칸이 순서대로 가리키는 말은? / `나가기` | 발전기 손잡이 | 조사카드 `C7 불이 들어온 안내 화면` 을 준다 |
| `D4 계기반 눈금자` | STOP — 눈금이 짚은 순서대로 다시 적으면? / `POST` | 다이어리 | 조사카드 `D6 눈금자 아래에서 나온 다이어리` 를 준다 |
| `F3 덜 만들어진 것` | 적힌 셈을 그 방 규칙대로 풀면 남는 두 글자는? / `데이` | 짝대기(-) | 조사카드 `F4 시험대에 놓인 시트` 를 준다 |
| `C6 확성기` | (퍼즐 없음) | 확성기 | 데이지의 시작 소지품으로만 남는다 |

**「짝대기(-)」는 이 시나리오에서 완전히 사라진 물건입니다.** 문에 꽂는 자리가
셋뿐이라 넷째 도구가 들어갈 데가 없습니다. COMBO 에서 「기호 하나를 도구로
줍는다」를 쓰고 싶으면 이쪽이 통째로 비어 있습니다.

## 3. 남긴 퍼즐 — 참고용

덜어낸 것을 다시 넣을 때 겹치지 않게, 지금 살아 있는 것도 적어 둡니다.

| 카드 | 문항 요지 | 정답 | 나오는 것 |
|---|---|---|---|
| `A9 몸 아래에 깔려 있던 것` | 메모리칩의 [LTL IKTI] 를 돌려 본다 | `녹취` | 조사카드 `A10 그 날 밤의 녹취` |
| `C1 멈춘 오락기` | [ERR OR DAY] 에서 에러를 지우면? | `DAY` | **도구** 회색조작기 |
| `C5 가짜 벽` | 손가락이 짚은 자리마다 빛나는 글자 | `전기` | **도구** 전기 |
| `H0 모니터 정원` | 무지개 색 순서대로 아홉 칸을 읽으면? | `DEAR TOY` | **도구** 게임팩 |
| `F1 폐기된 규칙들` | 버려지지 않고 남은 규칙 — 하늘은 어떻다? | `파랗다` | 구역 해금(하늘 끝) |
| `C4` · `D4` · `F3` | 위 2절 참고 | | 조사카드 |

방탈출 문(`ESCAPE`)의 마지막 문제 — 「세 자리에 도구 셋을 어느 순서로 넣는가」 —
는 아직 **더미**입니다. 실제 문항이 확정되면 그때 이 문서에도 옮겨 적습니다.
